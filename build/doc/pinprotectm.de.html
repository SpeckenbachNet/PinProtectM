Installation

PinProtectM stellt eine PIN vor deine ganze Website. Besucher sehen zuerst eine kleine PIN-Seite; wer die PIN kennt, kommt hinein. Benutzerkonten sind nicht nötig. Das Backend bleibt wie gewohnt erreichbar.

  1. Lade plg_system_pinprotect-<Version>.zip aus dem neuesten Release herunter.
  2. In Joomla: System → Installieren → Erweiterungen, die Datei hochladen.
  3. System → Plugins → System - PinProtectM: die PIN eintragen, dann das Plugin aktivieren.

Voraussetzungen: Joomla 6.0 oder neuer, PHP 8.3 oder neuer.

Solange keine PIN eingetragen ist, tut das Plugin nichts. Das Kontrollzentrum und die Plugin-Liste zeigen dann eine Warnung, damit du es merkst.

Zugang

Im Reiter Plugin legst du fest, wer hineinkommt und welche Seiten offen bleiben.

PIN

Der Code, den Besucher eingeben müssen. Er gilt für die Browser-Sitzung: Wer ihn einmal eingegeben hat, bewegt sich frei auf der Website, bis der Browser geschlossen wird.

Änderst du die PIN, wird beim nächsten Klick jeder nach der neuen gefragt, auch wer die alte gerade eben eingegeben hat.

Freie Menüpunkte (Allowed Menu Items)

IDs der Menüpunkte, die ohne PIN aufrufbar sind, durch Kommas getrennt, zum Beispiel 101,105. Die IDs stehen in der Liste der Menüeinträge in der Spalte ID. Das ist der sicherste Weg, einzelne Seiten offen zu lassen.

Freie URLs (Allowed URLs)

Ein Pfad pro Zeile, zum Beispiel /kontakt. Es zählt nur der Pfad der Adresse, nie der Teil nach einem Fragezeichen. Ein Eintrag muss ganze Abschnitte des Pfads treffen:

EintragGibt freiGibt nicht frei
/kontakt/kontakt, /de/kontakt, /kontakt/seite-2/kontakt-alt, /news?x=/kontakt

Das Sprachkürzel davor (/de/) und ein Ordner, in dem Joomla installiert ist, sind erlaubt. Ein Eintrag gilt also für alle Sprachen.

Impressum und Datenschutzerklärung brauchen hier keinen Eintrag: Sobald du sie unter Rechtliche Links einträgst, sind sie von selbst ohne PIN aufrufbar.

Adressen ohne SEF (index.php?option=…) lassen sich nicht als URL eintragen. Nimm dafür die ID des Menüpunkts.

Angemeldete Benutzer ausnehmen (Skip Logged-in Users)

Angemeldete Benutzer deiner Website brauchen keine PIN. Standardmäßig aus.

Damit man sich auf der Website anmelden kann, muss die Anmeldeseite selbst ohne PIN aufrufbar sein: Trag ihre Menüpunkt-ID unter Freie Menüpunkte ein.

Fehlversuche

Der Reiter Sicherheit (Security) schützt die PIN vor dem Erraten.

  • Fehlversuche (Wrong Attempts) – nach so vielen falschen PINs von einer IP-Adresse wird die Eingabe gesperrt. Standard 5; 0 schaltet die Sperre ab.
  • Sperre (Minuten) (Lock (Minutes)) – so lange dauert die Sperre. Standard 5 Minuten.

Während der Sperre zeigt die PIN-Seite eine Meldung, auch wenn die richtige PIN eingegeben wird.

Die richtige PIN setzt den Zähler zurück. Fehlversuche sind vergessen, wenn die Sperrzeit ohne neuen Fehlversuch vergangen ist.

Besucher mit derselben IP-Adresse, zum Beispiel in einem Büro oder Haushalt, teilen sich auch die Sperre. Die Tippfehler einer Person können die anderen für ein paar Minuten aussperren.

Wo die Fehlversuche gespeichert werden

Im Joomla-Cache, in der Gruppe plg_system_pinprotect (beim Datei-Handler im Ordner cache/plg_system_pinprotect/). Die IP-Adresse wird nur als Hash gespeichert, nie im Klartext. Das funktioniert unabhängig davon, ob der Cache in der globalen Konfiguration eingeschaltet ist.

Sperre aufheben

System → Cache leeren, die Gruppe plg_system_pinprotect auswählen und löschen. Alle Zähler und Sperren sind damit auf einen Schlag weg.

PIN-Seite

Im Reiter PIN-Seite (PIN Page) gestaltest du, was Besucher sehen.

Kopfbereich und Fußbereich (Header, Footer)

Inhalt über und unter der PIN-Box, mit dem Editor geschrieben: ein Logo, ein Begrüßungstext, ein Hinweis, wen man nach der PIN fragt.

Seiten, die du hier verlinkst, müssen ohne PIN aufrufbar sein, sonst fragen auch sie danach (siehe Zugang).

Stylesheet

Optional: ein Stylesheet für die PIN-Seite, relativ zum Website-Stammverzeichnis oder als vollständige Adresse. Beim Template Cassiopeia ist das zum Beispiel media/templates/site/cassiopeia/css/user.css.

Eigenes CSS (Custom CSS)

Zusätzliche Styles nur für die PIN-Seite.

Reihenfolge der Styles

Die PIN-Seite lädt ihre Styles in dieser Reihenfolge. Was später kommt, gewinnt:

  1. die eingebauten Styles des Plugins (Grundlayout),
  2. das Stylesheet,
  3. das Eigene CSS.

Das Stylesheet überschreibt also das eingebaute Aussehen, und das eigene CSS überschreibt beides. Eine Regel, die sicher gewinnen soll, gehört ins eigene CSS.

Diese Klassen stehen zur Verfügung:

KlasseElement
.pinprotectder ganze Inhalt der Seite
.pinprotect-headerKopfbereich
.pinprotect-boxdie weiße PIN-Box
.pinprotect-errorFehlermeldung in der Box
.pinprotect-inputPIN-Feld
.pinprotect-buttonKnopf Senden
.pinprotect-linksImpressum und Datenschutz unter der Box
.pinprotect-footerFußbereich
.pinprotect-noticeDatenschutzhinweis unten

Beispiel:

.pinprotect-button { background: #88A186; border-color: #88A186; }
.pinprotect-notice { background: #A391B2; }

Rechtliche Links

Impressum und Datenschutzerklärung müssen von jeder Seite aus erreichbar sein, auch von der PIN-Seite. Darum kümmert sich der Reiter Rechtliche Links (Legal Links).

  • Impressum (Imprint) und Datenschutzerklärung (Privacy Policy) – die Adressen der beiden Seiten, zum Beispiel /impressum. Beide erscheinen als Links unter der PIN-Box und sind ohne PIN aufrufbar. Ein leeres Feld bedeutet: kein Link.
  • Datenschutzhinweis (Privacy Notice) – eine Leiste unten auf der PIN-Seite erklärt, dass ein technisch notwendiges Sitzungs-Cookie gespeichert wird, mit einem Link zur Datenschutzerklärung. Besucher schließen sie mit Verstanden, der Browser merkt sich das. Standardmäßig an.

Updates

Joomla sucht selbst nach neuen Versionen von PinProtectM. Sie erscheinen unter System → Aktualisieren → Erweiterungen und lassen sich mit einem Klick installieren; deine Einstellungen bleiben erhalten.

Was sich in jeder Version geändert hat, steht auf der Release-Seite.

Über PinProtectM

System-Plugin für Joomla, das die gesamte Website mit einem PIN-Code schützt, mit Ausnahmen für einzelne Menüpunkte und URLs.

PinProtectM hält zufällige Besucher und Suchmaschinen fern. Es ersetzt keine echten Benutzerkonten: Wer die PIN kennt, kommt hinein.
