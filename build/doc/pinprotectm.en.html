Installation

PinProtectM puts one PIN in front of your whole website. Visitors see a small PIN page first; whoever knows the PIN gets in. No user accounts are needed. The backend stays open as usual.

  1. Download plg_system_pinprotect-<version>.zip from the latest release.
  2. In Joomla: System → Install → Extensions, upload the file.
  3. System → Plugins → System - PinProtectM: set the PIN, then enable the plugin.

Requirements: Joomla 6.0 or later, PHP 8.3 or later.

As long as no PIN is set, the plugin does nothing. The Control Panel and the plugin list then show a warning, so you notice it.

Access

The tab Plugin decides who gets in and which pages stay open.

PIN

The code visitors have to enter. It is valid for the browser session: whoever entered it once can move around the site freely until the browser is closed.

If you change the PIN, everyone is asked for the new one at their next click, also those who entered the old PIN a moment ago.

Allowed Menu Items

IDs of menu items that open without a PIN, separated by commas, for example 101,105. You find the IDs in the list of menu items, in the column ID. This is the safest way to keep single pages open.

Allowed URLs

One path per line, for example /contact. Only the path of the address counts, never the part after a question mark. An entry has to match whole parts of the path:

EntryOpensDoes not open
/contact/contact, /en/contact, /contact/page-2/contact-old, /news?x=/contact

The language code in front (/en/) and a folder Joomla is installed in are allowed, so one entry works for every language.

Imprint and privacy policy don't need an entry here: once you fill them in under Legal Links, they open without a PIN by themselves.

Addresses without SEF (index.php?option=…) can't be entered as URLs. Use the menu item ID for those.

Skip Logged-in Users

Logged-in users of your website don't need the PIN. Off by default.

To log in on the website, the login page itself has to open without a PIN: enter its menu item ID under Allowed Menu Items.

Wrong Attempts

The tab Security protects the PIN against guessing.

  • Wrong Attempts – after this many wrong PINs from one IP address, entering a PIN is locked. Default 5; 0 switches the lock off.
  • Lock (Minutes) – how long the lock lasts. Default 5 minutes.

During the lock the PIN page shows a message, even if the correct PIN is entered.

The correct PIN clears the counter. Wrong attempts are forgotten once the lock time has passed without a new one.

Visitors sharing one IP address, for example in an office or a household, also share the lock. One person's typos can lock out the others for a few minutes.

Where the attempts are stored

In Joomla's cache, in the group plg_system_pinprotect (with the file handler in the folder cache/plg_system_pinprotect/). The IP address is stored only as a hash, never in plain text. This works whether caching is switched on in the Global Configuration or not.

Lifting a lock

System → Clear Cache, select the group plg_system_pinprotect and delete it. All counters and locks are gone at once.

PIN Page

The tab PIN Page shapes what visitors see.

Header and Footer

Content above and below the PIN box, written with the editor: a logo, a welcome text, a hint whom to ask for the PIN.

Pages you link here have to open without a PIN, otherwise they ask for it too (see Access).

Stylesheet

Optional: a stylesheet for the PIN page, relative to the site root or as a full address. With the template Cassiopeia this is for example media/templates/site/cassiopeia/css/user.css.

Custom CSS

Additional styles for the PIN page only.

Order of the styles

The PIN page loads its styles in this order. Later ones win:

  1. the built-in styles of the plugin (basic layout),
  2. the Stylesheet,
  3. the Custom CSS.

So the stylesheet overrides the built-in look, and the custom CSS overrides both. A rule that has to win for sure belongs in the custom CSS.

These classes are available:

ClassElement
.pinprotectthe whole content of the page
.pinprotect-headerheader
.pinprotect-boxthe white PIN box
.pinprotect-errorerror message in the box
.pinprotect-inputPIN field
.pinprotect-buttonbutton Send
.pinprotect-linksimprint and privacy policy below the box
.pinprotect-footerfooter
.pinprotect-noticeprivacy notice at the bottom

Example:

.pinprotect-button { background: #88A186; border-color: #88A186; }
.pinprotect-notice { background: #A391B2; }

Legal Links

Imprint and privacy policy have to be reachable from every page, the PIN page included. The tab Legal Links takes care of that.

  • Imprint and Privacy Policy – the addresses of the two pages, for example /imprint. Both appear as links below the PIN box and open without a PIN. Leave a field empty for no link.
  • Privacy Notice – a bar at the bottom of the PIN page explains that a technically necessary session cookie is stored, with a link to the privacy policy. Visitors close it with Got it; the browser remembers that. On by default.

Updates

Joomla looks for new versions of PinProtectM by itself. They appear under System → Update → Extensions and install with one click; your settings stay.

What changed in each version is on the release page.

About PinProtectM

System plugin for Joomla that protects the entire website with a PIN code, with exceptions for selected menu items and URLs.

PinProtectM keeps casual visitors and search engines out. It is not a replacement for real user accounts: everyone who knows the PIN gets in.
